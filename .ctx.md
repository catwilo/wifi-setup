# wifi-setup -- context

## que es
Gestor de red para Debian (equipo "db"). Maneja: upstream wifi/cable, MAC persistente,
forward/NAT, SSH reachable, y failover de uplink. Entrypoint: bin/wifi (dispatcher por
subcomando). Libs en lib/. Modelo dhcpcd puro (la IP la asigna el AP, no se fuerza).

## arquitectura / donde esta que
- bin/wifi            dispatcher; cada subcomando = funcion _cmd_<x>. Carga libs con _source_common.
- lib/common.sh       define BASE_DIR y STATE_DIR (=BASE_DIR/state). Source primero.
- lib/detect.sh       detect_ssh_iface() -> iface por donde entra el SSH (CRITICO seguridad).
- lib/uplink.sh       failover PRIMARY/FALLBACK no-preemptivo (#8). Config: STATE_DIR/uplink-role.conf
- lib/net.sh forward.sh ssh.sh  red/NAT/ssh.
- dhcpcd-hooks/90-wifi-setup-uplink  hook que dispara failover en NOCARRIER.
- install.sh          INSTALL_DIR=/opt/wifi-setup. Copia bin/lib/*.sh ahi + symlink /usr/local/bin/wifi
                      + instala el hook en /lib y /usr/lib/dhcpcd/dhcpcd-hooks/.

## DEPLOY (no obvio, leer antes de tocar)
- El deploy REAL es /opt/wifi-setup (NO es basura vieja, es el destino de install.sh).
- `wifi` en PATH = symlink /usr/local/bin/wifi -> /opt/wifi-setup/bin/wifi.
- El repo (~/unix-toolkit-tools/wifi-setup) es la FUENTE; install.sh copia a /opt.
- Tras editar el repo hay que correr install.sh para desplegar a /opt.

## gotchas
- repo#id en zsh: `miko note wifi-setup#8 ...` FALLA (zsh trata # como glob). Usar comillas:
  `miko note "wifi-setup#8" ...`.
